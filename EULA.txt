7. Network use
Meridian Desktop sends network requests only to a Meridian server on the same computer. The
server address comes from the local_url setting, and it must be http on 127.0.0.1, localhost or
::1. The desktop refuses any other host, does not use a proxy and does not follow redirects. It
checks that server with a request to its /health path, and it reads RunPod status through that
server. The desktop does not contact usemeridian.us, RunPod or any other host. It does not send
the RunPod key anywhere: the key stays in the operating system credential store on this
computer. The hosted_url and engine_url settings are stored, but this version sends no request
to them. The Meridian server is a separate program, and this section does not cover its own
network use.
